# Reports

Generated by `make notebook` on a real FD02 export. Tables and figures are git-ignored until a real run is committed deliberately, so this folder only tracks this README and `figures/.gitkeep`.

- `threshold_selection.csv`: validation threshold grid with alert rate, FP, missed-fraud amount, expected cost and feasibility.
- `policy_test_report.json`: chosen threshold, test metrics, naive `t = 0.5` comparison and Brier scores before and after calibration.
- `figures/`: cost curve (validation), reliability diagram (test) and alert rate by 6-hour window (test).
